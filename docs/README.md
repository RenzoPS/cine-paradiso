# Documentación del proyecto

| Carpeta / archivo | Qué va |
|-------------------|--------|
| `esquema-de-tablas.drawio` / `.png` | Esquema de tablas con PK, FK y atributos. Se edita en [app.diagrams.net](https://app.diagrams.net) y se vuelve a exportar el PNG |
| `mockups/` | Mockups del sitio y del backoffice (Hito 1). Imágenes o export de la herramienta que usemos |
| `informe/` | Informe final: carátula, integrantes, resumen, introducción, solución, tecnología y conclusión |

La documentación técnica de la API vive en `api/docs/swagger.yaml`.
